Ошибки симплектических схем на квадруполе QF1A

Квадруполь QF1A (sila2026.lte): L = 0,308 м, K1 = 2,3667 м⁻²; нормальный, k₁ = k₁ᵥ = K1.

Частица на входе: x = 1 мм, pₓ = 0, y = 0,5 мм, py = 0, t = 0, δ = 0.

Точное решение (толстая линза), набег фазы φ = √K1·L = 0,4738 рад: x = x₀ cos φ = 0,8898 мм, pₓ = −x₀√K1 sin φ = −0,7020 мрад.
